# picoCTF — Obedient Cat
## Challenge Information

## - Platform: picoCTF
## - Category: General Skills
##  - Difficulty: Beginner
## - Status: Solved

## Objective

Retrieve the flag from the provided challenge file.

## Solution

### 1. Identify the file

I downloaded the challenge attachment and located it in my Downloads folder.

file <filename>

This command identifies the file type.

### 2. Read the file

cat <warm>


The command displayed the file's contents, revealing the flag.

### 3. Submit the flag

I submitted the flag on picoCTF and confirmed that the challenge was solved.

### Flag

What I Learned

- How to identify a file using "file".
